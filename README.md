# Конструктор таблицы приёма лекарств

Онлайн-конструктор для создания распечатываемых таблиц приёма лекарств.
Работает полностью в браузере, без сервера.

## Возможности

- Настройка периода (дата начала + длительность 1–4 месяца)
- Добавление/удаление лекарств с указанием:
  - Названия, дозы, примечания (когда принимать)
  - Время приёма: утро / вечер
  - Тип: постоянно / временно (с диапазоном дат)
- Разбивка на страницы: по неделе, 2 недели, месяцу или без разбивки
- Настраиваемое количество пустых строк для своих лекарств
- Альбомная / книжная ориентация
- Автомасштабирование чекбоксов под размер страницы
- Автоматическая история изменений с возможностью отката
- Регулируемая ширина панели настроек
- Экспорт и импорт резервной копии в JSON
- Печать напрямую из браузера
- Скачивание готового standalone HTML-файла

## Использование

Откройте `index.html` в браузере. Настройте лекарства и период, нажмите «Печать».

### Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub
2. Settings → Pages → Source: `main` branch
3. Сайт будет доступен по адресу `https://<username>.github.io/drug-schedule/`

## Технологии

Чистый HTML/CSS/JavaScript, без фреймворков и сборщиков.
